# 8단계: 이미지 주석 편집기

생성: 2026-10-03 12:49

## 배경
- 기준 문서: `PLAN.md`(포함 범위 3번 "주석 편집기", 디자인 M1), `CLAUDE.md`(캡처·핀·미리보기 구조, 이 맥의 함정).
- 1~7단계 완료(2026-10-03): 큐·DB·감시, 붙여넣기·HUD, 패널, 캡처·핀, OCR — 모두 사용자 실조건검증.
- 사용자가 윈도우판에서 매일 쓰는 묶음 "캡처·핀·주석"의 마지막 조각.
- 윈도우판 참고: https://github.com/mw3love/Paste_flow `pasteflow/ui/image_annotator.py`(3230줄 — 전부 옮기지 말 것, 동작만 참고). 원본 CLAUDE.md의 `image_annotator.py` 항목에 함정이 적혀 있음.

## 윈도우판 동작 (코드에서 확인)
- 도구와 숫자키: 1 선택 · 2 네모 · 3 화살표 · 4 텍스트 · 5 원 · 6 선 · 7 펜 · 8 번호(배지).
- 도형은 4px 미만으로 끌면 버림(실수 클릭 방지). 그린 뒤 손잡이로 크기 조절, 선택 후 이동·삭제.
- 도구마다 색·두께 기본값을 따로 기억(`tool_defaults`), 색 스포이드(돋보기 `_ColorLoupe`), 두께 단계 조절(`_SizeStepper`), Ctrl+Z 되돌리기.
- 진입: 핀·이미지 미리보기 창에서 Space(편집 모드). 저장 시 결과 이미지를 클립보드·히스토리로.

## 할 일
1. 범위 정하기(사용자와): 위 8도구 전부 vs 자주 쓰는 것 먼저(네모·화살표·텍스트·번호 추정). 단축키 1~8 유지 여부.
2. 진입점: `PinWindow`·`PreviewWindow`에서 Space(또는 E) → 편집 모드. 결과 → 클립보드(감시기가 히스토리·큐에 넣음) + 핀 이미지 교체.
3. 구조: AppKit 커스텀 NSView(도형 목록을 모델로 두고 그리기) — 도형 모델·되돌리기 스택·히트 테스트는 `PasteFlowCore`에서 테스트.
4. 디자인: M1 토큰, 툴바는 윈도우판처럼 이미지 위/아래 작은 바. 아이콘은 SF Symbols.

## 끝의 기준
- 도형 모델·되돌리기·번호 자동 증가 테스트 통과.
- 캡처 → 핀 → Space → 네모·화살표·텍스트·번호를 그리고 저장 → 결과가 클립보드·패널 히스토리에 생기고 다른 앱에 붙음(사용자 실조건검증).
- 그리기 손맛(끌기·손잡이)은 사용자 확인.

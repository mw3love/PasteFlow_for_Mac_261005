## 윈도우판 패널 동작 (참고)
- 크기 320×420(최소 260×390), 프레임 없는 창, 드래그 이동, 헤더 = 상태 `붙여넣기 n/total`(큐 있을 때만) + 핀(항상 위에, 기본 켜짐) + 닫기. **검색 없음(의도적 제거).**
- 섹션 `고정메모` / 구분선 / `히스토리`, 각각 접기. 항목 최대 5줄, 이미지 썸네일 96×72.
- 큐 표시: 큐 안 = 코랄 선, 다음 항목 = 옅은 코랄 채움, 지나간 항목 = 흐린 글자.
- 클릭 선택, 더블클릭/Space = 미리보기(여러 창 동시, 이미지 휠 줌·드래그), Enter = 붙여넣기, Del = 삭제, P = 고정/해제, Esc = 닫기.
- 우클릭: 미리보기 / 큐에 추가·해제(C) / 복사 / 파일로 저장 후 경로 복사(S) / 파일 위치 열기(O) / 수정(고정 항목 글자) / 고정추가·해제(P) / 삭제(Del). 빈 곳 우클릭: 패널 숨기기·히스토리 초기화·설정·종료.
- 끌어다 놓기: 항목을 다른 앱으로(이미지는 이미지로), Alt(맥은 ⌥)+드래그면 이미지를 임시 PNG 경로 글자로. 고정 항목끼리 드래그로 순서 바꾸기, 히스토리→고정 영역 드롭 = 고정.
- 히스토리에서 지우면 큐에서도 제거(`PasteQueue.remove`) — 진행 HUD도 갱신.

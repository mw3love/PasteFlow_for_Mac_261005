## 윈도우판 동작 (재현 대상)
- **영역 캡처**: 키를 누르는 순간 모든 모니터를 "얼린" 스크린샷 위에 오버레이. 커서 아래 창을 하이라이트(창 단위 스냅 — PLAN.md: 요소 단위 스냅은 v1 마지막 단계), 좌클릭 = 하이라이트 창 캡처, 4px 이상 끌면 자유 사각형, 우클릭/Esc = 취소, Space = 실제 커서 포함 토글. 결과 → 클립보드 + 히스토리 + 순차 큐(복사와 같은 경로, 단 자기 복사로 다시 기록되지 않게) + 파일 저장 + 알림. 캡처한 사각형을 기억(핀 위치용).
- **화면 핀**: 큐에 남은 항목이 있으면 다음 항목을(순차 붙여넣기와 포인터 공유), 없으면 현재 클립보드 이미지/텍스트를 떠 있는 창으로. 원본 1:1(화면보다 크면 축소), 여러 개, Esc 닫기, 텍스트는 이미지로 그려서 핀. 직전 경로 붙여넣기의 PNG 경로 글자면 원본 이미지로 복원.

## 맥에서 정할 것·확인할 것
- 캡처 수단: ScreenCaptureKit(`SCScreenshotManager`, macOS 14+) vs `CGWindowListCreateImage`(폐기 예정 경고 여부 확인). 화면 기록 권한은 이미 있음.
- 창 사각형: `CGWindowListCopyWindowInfo`(layer 0, 자기 창 제외). 메뉴바·Dock은 별도 처리.
- 오버레이: 모니터마다 창 1개, 전체 화면 앱 위에도(`canJoinAllSpaces`·`fullScreenAuxiliary`, 높은 level). Retina 배율·여러 모니터 걸침.
- 저장 폴더 기본값: 사용자에게 물어볼 것(예: `~/Pictures/PasteFlow` vs 바탕화면). 파일 이름 규칙도.
- `ClipboardMonitor.noteSelfChange()`와 `onCopy` 경로를 재사용해 "복사와 똑같이" 히스토리·큐에 넣기(중복 기록 방지).
- 핀의 Space(주석 편집)는 8단계 범위 — 이번엔 자리만.

## 끝의 기준
- `⌘⇧2` → 창 클릭 / 자유 드래그로 캡처 → 패널 히스토리에 이미지가 생기고 큐에 들어감 → `⌃⌘V`로 터미널에 경로가 붙음. 저장 폴더에도 파일이 있음.
- 캡처 세 번 후 `⌘⇧1` 세 번 → 캡처1·2·3이 차례로 화면에 핀됨. 큐가 비면 클립보드 내용이 핀됨.
- Chrome 전체 화면 위에서도 오버레이·핀이 뜸 — 스크린샷으로 자체 확인, 손맛(드래그)은 사용자 확인.

## 지금 상태 (코드에서 확인)
- 단축키는 `PasteFlowCore/Hotkeys.swift`에 키 코드·수식키로 고정 판정(`PasteAction`·`ScreenAction`, `isPanelToggle`). 바꾸려면 DB 설정에서 읽는 구조로 바꿔야 함.
- 설정 창은 `OCRSettingsWindow` 하나뿐(메뉴바·패널 빈 곳 우클릭). 일반 설정 창 없음.
- `Toast`는 하나만 띄움(주석에 "9단계에서 여러 개 쌓기·설정 on/off로 확장 예정").
- 큐 idle 초기화 시간은 DB `queue_idle_reset_sec`로 이미 읽음. 캡처 저장 폴더는 `capture_save_folder`.
- 단일 인스턴스·자동 시작은 아직 없음.

## 할 일
1. 범위 정하기(사용자와): 설정창에 넣을 항목(단축키 8개, 큐 idle 초, 캡처 저장 폴더, 토스트 on/off, 자동 시작, OCR 설정 통합 여부).

3. 단일 인스턴스: 같은 번들 ID가 이미 실행 중이면 새 쪽이 종료.
4. 단축키 변경: 키 녹화 칸 + 겹침 경고(PLAN.md "피한 키"·"알려진 겹침" 참고). 판정 로직은 Core에서 테스트.

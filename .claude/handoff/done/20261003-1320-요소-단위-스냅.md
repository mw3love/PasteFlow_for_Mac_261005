## 할 일
1. 먼저 실측: 손쉬운 사용(AX) API로 커서 아래 요소 사각형을 얼마나 빨리·정확히 얻는지 Chrome·VS Code·Finder·Safari에서 확인(`AXUIElementCopyElementAtPosition`, 창 단위 `AXUIElementCreateApplication` → 자식 순회). 크롬·일렉트론은 접근성 트리가 꺼져 있을 수 있음(`AXEnhancedUserInterface`/`AXManualAccessibility` — 확인 필요).
2. 실측 결과를 사용자에게 보여 주고 할지 말지 정하기(품질이 낮으면 포기도 선택지 — "시도" 단계).
3. 한다면: 캡처 오버레이가 "얼린" 화면을 쓰므로 요소 사각형은 오버레이를 띄우기 직전에 미리 모아 두거나 커서 이동마다 물어야 함 — 속도 실측으로 결정.
